# insurer

`insurer` is a learning sandbox and the seed of an AI-native insurer: a small owned insurance core for **Agent Spend Cover**, embedded cover for losses from AI-agent purchases made through Valet. It uses sandbox money only; it is not a licensed insurer and does not make real payments.

## Quickstart

Requires Python 3.10.

```bash
python3.10 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
insurer simulate --db book.db --out results.json
insurer report --results results.json --out report.html
insurer recalibrate --db book.db --out proposal.json
insurer serve
```

The simulator writes a deterministic `results.json` for a given seed when `--llm-sample 0`. Its real policy and claims flows post to a SQLite double-entry ledger; `insurer trial-balance` shows account totals. Gemini routing is optional and only enabled by setting `GEMINI_API_KEY` and requesting a nonzero `--llm-sample`.

The report command writes a single self-contained HTML file with KPIs, a monthly premium/loss-ratio chart, segment pricing vs truth, a loss triangle, claim decisions, capital, a claims explorer, and the trial balance.

Recalibration reads a persistent simulation book and writes an experience-based frequency-factor proposal. Add `--write-product candidate.yaml` to create an unsigned next-version candidate; review it before committing it as the human sign-off.

Use `insurer simulate --product candidate.yaml --out results-v2.json` to simulate an unsigned candidate; omitting `--product` continues to use the default product.

Other entry points include `insurer quote --profile '{...}'`, `insurer bordereaux premium --month 2027-01`, and `insurer trial-balance`. Agent Ops Cover adds `insurer agent-quote --db insurer.db --scorecard scorecard.json --start-date 2027-01-01 [--bind]` and `insurer agent-claims --db insurer.db --policy P-... --manifest manifest.yaml --traces traces.jsonl --notified-date 2027-01-10`. See [the Agent Ops Cover guide](docs/AGENT_RISK.md#agent-ops-cover). `insurer serve` exposes the quote, policy, claim, ledger, and bordereaux API. Set `INSURER_DB` to choose its SQLite file.

## Agent-risk evidence MVP

This separate evidence-only MVP is **not related to Valet or Agent Spend Cover**. It ingests an agent manifest, OTLP/JSON traces, insurer-owned exam results, and optional customer CI evals; it produces a per-peril scorecard, not premiums, policies, or claims. See [the agent-risk guide](docs/AGENT_RISK.md).

Core installs stay small; install the pinned demo stack separately with `pip install -e '.[demo]'`. Set `GEMINI_API_KEY` in the environment, then start a local demo harness:

```bash
AGENT_KIND=refund AGENT_VARIANT=weak \
  python -m uvicorn examples.agents.harness:app --host 127.0.0.1 --port 8000
```

In a second terminal, replay synthetic sessions, run the insurer exam, and score the resulting evidence:

```bash
python -m examples.agents.traffic --agent-kind refund \
  --endpoint http://127.0.0.1:8000 --out-traces refund-weak.jsonl
insurer agent-exam --manifest examples/agents/manifests/refund_bot.yaml \
  --endpoint http://127.0.0.1:8000/invoke --out refund-weak-exam.json
insurer agent-score --manifest examples/agents/manifests/refund_bot.yaml \
  --traces refund-weak.jsonl --exam refund-weak-exam.json --out refund-weak-score.json
```

Switch `AGENT_VARIANT` to `hardened` for the hardened version, or use `AGENT_KIND=kyc` with `examples/agents/manifests/kyc_bot.yaml` for the Google ADK demo. The demos use synthetic data only. ADK message-content capture is enabled for trace evidence; do not send real customer data.
